# 야생광장 바이블

코드네임 pokeWorld. 플레이어에게 보이는 이름은 야생광장. 사용자는 대표다. 이 문서와 다른 규칙을 만들지 않는다. 바꿔야 하면 변경 한 줄만 대표에게 올린다.

## 제품

스마트폰 세로 게임. 한 판 10–20분. 친구들이 초대 코드 6자리로 같은 광장에 모여 오리지널 크리처를 잡고, 대전하고, 교환한다. 판정은 Railway의 game-api가 한다.

포켓몬스터의 이름, 기술, 그림, 도감, 울음소리, 맵은 쓰지 않는다.

## 하지 않는 것

지도 위 이동, 자유 입력 채팅, 교배, 글로벌 거래소, 랭크전, 결제, 가챠, 음성, 크리처 임의 지급.

## 규칙

- 타입은 풀, 물, 불, 땅. 파티 3. 레벨 상한 20. 기술은 2개이고 하나는 무상성.
- 턴 20초. 넘기면 첫 기술. 경험치는 야생 승리만. 플레이어 대전 첫 승만 하루 한 번 보너스.
- 볼은 시작 10, 상한 30, 자정(KST)에 +3. 포획 주사위는 서버만. 체력이 낮을수록 확률이 오른다.
- 응원은 같은 광장의 친구가 야생전 중일 때 포획률 +8%p, 배틀당 1회.
- 광장당 40명. 운영 상한은 8–40. 이미 안에 있는 사람은 상한을 낮춰도 나가지 않는다.
- 말풍선은 정해진 8문장, 3초. 안녕, 이쪽이야, 풀숲 가자, 한 판 하자, 좋아, 잠깐, 보스 대기, 잘 가.
- 교환은 같은 광장, 양쪽 확인, 10초 취소. 끝나면 어느 쪽 파티도 0이 되면 거절. 한 SQL 트랜잭션.
- 필드 보스는 21:00–21:15 KST, 광장 북쪽, 최대 4인, 빈자리는 광장지기 하루, 포획 불가.
- 오늘 출현 1종은 풀숲에 더해진다. 후보: 흙두더지, 연못개구리, 솔방울새, 이슬잠자리, 햇살나비, 안개여우. 비어 있으면 상주 3종만.
- 광장에 도착하면 파티 체력이 찬다. 회복 버튼은 없다.

## 서버

- Railway 프로젝트 pokeworld. game-api 1대, Postgres, Redis. 앱 설치 파일은 올리지 않는다.
- 레포는 `apps/mobile`(Expo), `apps/server`(Fastify, 서비스 루트), `packages/shared`(Zod).
- 클라이언트는 의도만 보낸다. 데미지, 포획, 경험치, 소유권은 서버 응답으로만 받는다.
- 대전 진행은 Redis. 소유권 변경만 Postgres에 커밋한다.
- 운영 화면은 다른 도메인의 같은 game-api `/admin`. 웹소켓을 쓰지 않는다. 운영자 개인 토큰, 감사 로그, 소유 변경은 볼 지급·자정 볼 재실행·교환 되돌리기뿐이다.

## 화면

- 광장이 뿌리. 고르기는 시트, 전투와 입장은 전체 화면. 주 버튼은 하단 하나.
- 서버 판정 전 버튼을 잠근다. 이름표는 화면당 6개. 말풍선은 동시에 2개.
- 단계 2의 광장은 혼자 걷는 들판이다. 다른 사람은 3단계에 같은 맵 위에 붙는다.

## 단계

1. 닉네임, 서버 건강, DB
2. 스타터, 야생 포획, 파티, 도감, 혼자인 광장. 운영은 현황·출현·플레이어·기록
3. 초대 코드, 사람, 말풍선
4. 대전 신청, 관전 2명
5. 응원, 교환, 21시 보스
